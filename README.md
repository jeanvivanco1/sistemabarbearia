Animado em compartilhar um projeto que desenvolvi para o primeiro semestre do curso de Analise e Desenvolvimento de sistemas e demonstrar minhas habilidades em Python e integração com bancos de dados: um Sistema de Agendamento para Barbearias via linha de comando!
Este sistema foi criado pensando na otimização da gestão de horários em barbearias, oferecendo funcionalidades essenciais como:
Cadastro simplificado de clientes.
Visualização clara de barbeiros e serviços disponíveis.
Agendamento de horários com seleção de cliente, barbeiro e serviço.
Ponto chave: Implementação de uma lógica robusta para verificação de conflitos, impedindo agendamentos duplicados para o mesmo barbeiro no mesmo horário ou para o mesmo cliente simultaneamente.
Consulta e cancelamento de agendamentos existentes.
Tecnologias e Habilidades Aplicadas:
Desenvolvimento da lógica da aplicação em Python.
Integração com banco de dados MySQL para armazenamento e recuperação eficiente de dados (clientes, serviços, agendamentos), utilizando a biblioteca mysql.connector.
Manipulação de datas e horas (datetime) para validações e controle preciso dos agendamentos.
Criação de uma interface de usuário interativa no console, com feedback claro para o usuário.
Este projeto representa minha capacidade de desenvolver soluções práticas e funcionais, desde a concepção da lógica até a interação com bancos de dados relacionais, habilidades cruciais para o desenvolvimento backend. Foi um excelente exercício para solidificar conhecimentos em SQL, Python e resolução de problemas.
